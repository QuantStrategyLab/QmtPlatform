# Code of Conduct

## Our Standards

Be respectful and constructive in issues, pull requests, and reviews. Disagree about code and approach, not about people.

## Project Scope

This is a focused, small-maintainer project. Discussion should stay on topic for `QmtPlatform`: the QMT/miniQMT A-share execution runtime, its dry-run guards, and its integration with `QuantPlatformKit` and `CnEquityStrategies`.

## Reporting and Enforcement

Report unacceptable behavior to `@Pigbibi`. Reports will be handled as discreetly as possible. Maintainers may remove comments, commits, or contributions that do not follow this Code of Conduct, or block contributors for repeated or serious violations.
